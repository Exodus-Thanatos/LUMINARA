Project Title - LUMINARA: SMART STREETLIGHT MANAGEMENT SYSTEM WITH CENTRALIZED SWITCHING AND PER-LAMP FAULT DETECTION FOR BARANGAY 6, CARMONA, CAVITE
Project Overview - This project reduces the need for manual, citizen-reliant streetlight status reporting and addresses the lack of digital streetlight logs in Brgy 6, Carmona. LUMINARA uses wireless light-sensor networking and remote circuit-switch control.
Objectives:
  a. Create a system that enables per-lamp state detection (up to a specific count of lamps);
  b. Create a system that enables aggregate circuit status readings and remote switch control;
  c. Create a dashboard that will record and log data, as well as integrate both objectives a and b.
Features:
  a. Per-Node Light Sensor readings (BH1750)
  b. LoRa Connectivity (Star Topology)
  c. Remote Circuit switching (Dashboard)
  d. Dashboard recordkeeping and state display
  Planned:
    a. Switch from battery (demo) to solar (final)
Technologies Used:
  a. Arduino (C++)
  b. HTML, CSS, Node.js, React
  c. BH1750 light sensor, SX21
